# Инструкция по установке APK на Android

## Проблема: "Не удалось открыть файл"

Если при нажатии на APK файл видите ошибку "Не удалось открыть файл", следуйте этим инструкциям:

## Шаг 1: Разрешить установку из неизвестных источников

### Для Android 8.0 (Oreo) и новее:

1. Откройте **Настройки** → **Безопасность** (или **Безопасность и местоположение**)
2. Найдите **Установка неизвестных приложений** (или **Неизвестные источники**)
3. Выберите приложение, через которое вы скачиваете APK (например, **Chrome**, **Файлы**, **Загрузки**)
4. Включите **Разрешить из этого источника**

### Для старых версий Android:

1. Откройте **Настройки** → **Безопасность**
2. Включите **Неизвестные источники** (или **Установка из неизвестных источников**)

## Шаг 2: Скачайте APK файл

1. Откройте GitHub Actions: https://github.com/elyorka22/minutka/actions
2. Найдите последний успешный workflow "Build Android APK"
3. Прокрутите вниз до секции **Artifacts**
4. Нажмите на **minutka-app-release**
5. Скачайте файл `app-release.apk`

## Шаг 3: Установите APK

### Способ 1: Через файловый менеджер

1. Откройте приложение **Файлы** (или **Загрузки**)
2. Найдите скачанный файл `app-release.apk`
3. Нажмите на файл
4. Нажмите **Установить**
5. Дождитесь завершения установки
6. Нажмите **Открыть**

### Способ 2: Через браузер

1. Скачайте APK через браузер (Chrome, Firefox и т.д.)
2. После скачивания откройте уведомление о загрузке
3. Нажмите на файл
4. Нажмите **Установить**

## Шаг 4: Если всё ещё не работает

### Проверьте размер файла

APK файл должен быть примерно 20-50 МБ. Если файл меньше 1 МБ, значит он не полностью скачан.

**Решение:** Скачайте файл заново.

### Проверьте архитектуру процессора

Если у вас 64-битный телефон, но APK для 32-битной архитектуры, может не установиться.

**Решение:** Скачайте правильный APK для вашей архитектуры (см. ниже про split APK).

### Очистите кэш

1. Откройте **Настройки** → **Приложения**
2. Найдите приложение, через которое скачиваете APK (Chrome, Файлы)
3. Нажмите **Очистить кэш**

### Перезагрузите телефон

Иногда помогает простая перезагрузка.

## Альтернатива: Установка через ADB (для разработчиков)

Если у вас есть доступ к компьютеру с ADB:

```bash
adb install app-release.apk
```

## Проверка установки

После установки:
1. Найдите приложение **Minutka Online Bozor** в списке приложений
2. Откройте приложение
3. Если видите ошибку подключения - это нормально, если бэкенд недоступен
4. Нажмите кнопку **Qayta urinish** (Повторить) для повторной попытки

## Если ничего не помогает

1. Убедитесь, что APK файл полностью скачан (проверьте размер)
2. Попробуйте скачать APK на компьютер, затем передать на телефон через USB/Bluetooth
3. Проверьте, что на телефоне достаточно места для установки
4. Убедитесь, что версия Android не слишком старая (минимум Android 5.0)
